# Book Tracker

A simple web app to keep a list of books to read, built with plain HTML, CSS and JavaScript (no frameworks, no backend).

**Live site:** <your link>

## Features
- Add a book (title and author required, status To read / Reading / Finished)
- List shown newest first
- Search by title or author (case-insensitive)
- Change a book's status
- Data saved in the browser (localStorage), so it survives a refresh
- Delete a book, status counts, phone-friendly layout

## How to run
Open `index.html` in a browser. No install needed.

## AI tools used
Antigravity (built in phases), with Claude for planning and review.
